SKU 编码规范

单件 SKU

格式：印花代号-款式代号-颜色代号-尺码（全称代号）

M-LWDX-WH-160     童装纯色-螺纹短袖-白色-160
S008-LWDX-WH-160  两颗心K印花-螺纹短袖-白色-160
纯色代号按仓库区分：越南 T/M，泰国 TT/TM

组合 SKU

各维度缩写连写（无分隔符），尺码唯一。例：纯色 T + 印花 S008 两件组合

TS8-LWDLWD-WHWH-160
│ │  │     │  │
T+S8  LWD+LWD  WH+WH  160（单尺码）
纯色   螺纹短袖×2  白色×2
缩写来自各库 A 列短编码（S008→S8、LWDX→LWD）

多仓库差异点（8 个参数）

参数点 🇻🇳 越南仓（男装） 🇹🇭 泰国仓（男装）
纯色代号MTM
SKU 前缀M-TM-
仓库名越南仓泰国仓
印花分类Print泰国Print
衣服分类Clothes泰国Clothes
组合装分类留空（归未分类）泰国SKU
字典硬编码dicyh("M")="纯色"dicyh("TM")="纯色"
扩展新国家仓 = 复制模板 → 全局替换这 8 个参数点 → 完成。童装版同构：男装代号把 M 换成 T。

2
